# 历史压测结果归档

本目录是开发过程中的历史压测数据，**只作过程留痕**，不作为当前性能结论的依据。
新的、可复现的对比数据请使用 `benchmark/docker/` 全流程生成到仓库根的 `bench-results/`。

## 环境说明（重要）

这批数据是在 Docker 统一环境建立之前采的，**CPU 型号、绑核、governor、编译器版本均未记录**，
且都是单次采样。因此：

- 只能看同一批次内的相对趋势（如 LT vs ET、主从开关前后）
- 不要与 `bench-results/` 中的 Docker 数据直接横比
- P99 在 pipeline 模式下的数值不可用（wrk 直方图伪影）

## 已有结论

- **08-24 这一对**：同一 commit 上主从 Reactor 的开关对比，中高并发吞吐显著提升，且超时消失
  （旧版 README 中“提升 3~8 倍”即来自这组数据，该机器条件已不可复现）
- **08-31 这一对**：LT vs ET 对照，1 万连接时 ET 明显占优（30.8万 vs 20.6万），
  与 ET 减少 `epoll_wait` 重复返回、降低 syscall 开销的预期一致；
  但在 Docker 统一环境 + 本机回环下该差距未复现（见根 README 性能基准）
